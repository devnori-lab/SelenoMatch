Backend integration guide

The page auto-detects the backend (badge top-right: LIVE or MOCK). Served from the backend it uses the same origin; opened as a file it uses http://localhost:8000 (override with ?api=http://host:port).

1 · Setup

  1. Create backend/ with FastAPI + uvicorn; enable CORS for the frontend origin.
  2. pip install torch kornia opencv-python rasterio numpy scipy onnxruntime fastapi uvicorn python-multipart (+ ISIS3 / Ames Stereo Pipeline via conda if needed).
  3. Structure: main.py, io_readers.py, normalize.py, pyramid.py, matcher.py, verify.py, explain.py, synth/render.py, train.py.

2 · Endpoints to implement

POST /api/upload        multipart file + sensor → {image_id, preview_png, meta{sun_el, sun_az, gsd}}
POST /api/match         {image_a, image_b, options} → {job_id}
GET  /api/jobs/{id}     → {status, stage, result}
result = {
  matches:[{p:[x,y], q:[x,y], conf:0.91, residual:0.4, reason:"crater rim…", kept:true}],
  transform:[[..],[..],[..]], rms:0.6, time_ms:1800,
  registered_png:"…", geotiff_url:"…"
}
POST /api/synth/generate {dem, shader, sun_el:[5,75], sun_az:[0,359], gsd_ratios, n}
POST /api/train         {stage, epochs}   +  WS /ws/train (progress)
GET  /api/benchmark     → table + curves
POST /api/export        {job_id, format: geotiff|json|png}

3 · Pipeline logic behind /api/match (in order)

  1. Read files: rasterio/GDAL for GeoTIFF and PDS; planetaryimage or spectral for IIRS cubes. Pick 2–3 reflectance bands and average into a pseudo-pan image.
  2. Normalize: local contrast (CLAHE), gradient maps; optional Lambertian de-shading from metadata Sun angles.
  3. Pyramid: downsample both to the coarse GSD, match, estimate transform, then refine at native OHRC resolution inside that footprint.
  4. Match: kornia.feature.LoFTR (start with pretrained), later swap in your fine-tuned weights.
  5. Verify: cv2.findHomography(..., cv2.RANSAC); compute residual per match; drop above threshold.
  6. Explain: template string per cluster (feature type, residual, confidence).
  7. Return JSON in the shape above; run as a background task and poll the job.

4 · Synthetic data (do this early)

  1. Load LOLA DEM tiles; compute slope/aspect with NumPy.
  2. Shade: I = max(0, n·s) with Sun vector s from (elevation, azimuth); add noise.
  3. Warp for scale changes; store known correspondences; train LoFTR with the matching loss.

5 · Deploy

  1. Export with torch.onnx.export; run with onnxruntime on CPU for the on-site demo.
  2. Serve frontend statically from FastAPI (StaticFiles).
uvicorn main:app --port 8000   →   open http://localhost:8000
